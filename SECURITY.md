# Security and privacy

This Skill is designed to keep real resume materials local. Do not commit real resumes, private profiles, photos, job descriptions, API keys, generated artifacts, or runtime traces. The checked-in examples are synthetic and must not be replaced with personal data.

The Skill treats approved source hashes, claim provenance, render manifests, and quarantine records as safety boundaries. Operators should review every generated resume before use and should not treat a passing automated gate as factual approval.

To report a security issue, open a private repository issue or contact the repository owner directly. Please include a minimal reproduction without personal data when possible.
